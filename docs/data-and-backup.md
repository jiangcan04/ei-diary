# 数据保存、备份与迁移

## 当前设备保存

照片、可编辑笔迹、日期和照片摆放位置保存在浏览器IndexedDB中，按网站来源隔离。网站地址的协议、域名或端口变化都可能进入另一份存储。空月历不一定代表旧记录已删除，先确认打开的是原网址及原浏览器环境。

同一网址在不同设备、不同浏览器或不同浏览器配置中不自动共享日记。首版无账号、云同步或应用锁；其他能使用同一浏览器存储的人可能看到记录。GitHub公开的是代码，不包含浏览器里的日记。

浏览器清除站点数据、系统回收存储、卸载或设备故障可能影响记录。不要使用无痕浏览作为长期日记存储。PWA安装及离线缓存不保证日记永久保存，也不是云备份。

## 导出整本备份

1. 编辑完成后点保存，确认已保存；若失败，先重试，不要关闭或清除数据。
2. 返回月历，打开右上角「···」日记本菜单，点「导出备份」。
3. 等待「备份已准备好，共…页」。点「存到文件」或「下载 ZIP」，按系统提示保存。若分享菜单无法打开，使用下载入口。
4. 到「文件」或下载目录确认ZIP真实存在。文件名形如「ei ？-备份-日期.zip」。保留完整ZIP，不拆包修改。
5. 复制到可靠的其他位置并定期更新，重要修改后也导出一份。把文件存到iCloud Drive等位置只是保存备份文件，不代表应用已经启用自动云同步。

备份包含照片和可编辑笔画，不是仅供观看的截图。ZIP未提供应用级加密，妥善保存，分享备份等于分享其中日记。恢复前应验证副本；不要为了试恢复而删除原设备数据。

## 在空白环境恢复

1. 在另一台设备或独立测试浏览器中打开应用；不要清空日常日记来制造空白环境。
2. 翻开本子，在月历菜单点「从备份恢复」，选择完整ZIP。
3. 等待检查，核对页数说明，再点「确认恢复」；不想导入时点「取消恢复」。
4. 完成后核对日期、页数、照片和笔迹。打开混合页，移动照片、追加笔迹并保存，确认仍可编辑。
5. 关闭后重开，再确认内容存在；验证完成后才考虑停用原环境。

同一页面按标识去重，重复恢复不新增副本。同标识存在不同修改时保留本机版本，不用备份覆盖，因此恢复不是回滚工具，也不是双向同步。无法识别或损坏的备份会被拒绝；写入失败时保留原有日记并允许重试。

## 换设备、换网址

先在旧环境导出并确认文件存在，再在新环境恢复，最后逐页抽查混合内容及重开结果。新旧环境后续编辑不会自动合并。想迁移备份中的特定旧版本时，使用独立空白环境；不要删除原环境记录来强制覆盖。

## 离线与更新

首次需联网成功加载应用资源，之后才可尝试离线重开、写画、贴本机照片及保存。仍受设备可用空间与浏览器支持影响。相册中尚未下载到本机的云端照片可能需要联网。

应用更新先结束编辑并保存，再接受更新。更新保持同一网址；代码回退不能恢复已清除的日记。恢复只依靠已有完整备份。自己部署网站仍按以上本机数据规则运行。

## 本说明的验收

使用专门制作的一张测试照片和笔迹创建混合页，按导出和空白环境恢复步骤操作。核对照片位置、日期、页数及笔迹可编辑；重开确认保存，重复导入确认不增页。不要用真实日记做公开截图。检查README入口、图片及文档相对链接均可打开；未完成的部署教程与仓库地址须继续明确标注待完成。
